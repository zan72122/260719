# スケスケなかみランド

スケスケ断面の機械を、指でいじって動かす4歳向けのタッチゲーム集です。
「見えない場所で何かが動いて、それが外の結果に変わる」瞬間を楽しむ遊びです。

方針: **写実3D**。実在の道具をマクロ撮影したような画づくりと、実物準拠の機構。
全14ゲームすべて Three.js による WebGL 描画です。

日用品4機種に加えて、**現実にはなかなか動かせない機械10機種**を収録しています。
1回ごとにお金がかかるもの（クレーンゲーム・洗車機）、一発勝負のもの（消火器・
打ち上げ花火・ロケット）、知ってはいるが触れないもの（蒸気機関車・自動改札機・
銀行の金庫）、一回性が重いもの（エレベーター機械室・フィルムカメラ）。
どれも中の連鎖反応が断面で見えます。

もうひとつの方針: **入力と出力を1対1にしない**。押す速さ・深さ・位置・順序・
タイミングの小さな違いが物理で増幅され、何百通りもの結果に分岐します。
乱数ではなく入力差の増幅が主体なので、同じ操作を再現できれば同じ結果になります。
さらに世界が状態を記憶する（インクが減る・地面の濡れ模様が育つ・液だまりが乾く）ため、
同じ操作でも「いつやるか」で結果が変わります。

## あそびかた

`index.html` をブラウザで開くだけで遊べます（ビルド不要・オフラインOK・Three.js同梱）。
iPad / iPhone の Safari、縦画面・横画面のどちらでも遊べます。
GitHub Pages などの静的ホスティングにそのまま置いても動きます。
どのゲームも、何もない場所をドラッグすると視点を回して機構を観察できます。

## 収録ミニゲーム

### 🖊️ ぺん（ノック式ボールペンの中身）
実在の透明軸ノック式ボールペンを再現。屈折する透明ボディの中に、
バネ鋼のコイル・回転カム式ラッチ・真鍮のペン先・インク入りリフィルが見えます。

- 紺色ボタンを押す → バネが圧縮 → 最下点でカムが1歯回って「カチッ」
  → 指を離すと戻り行程でラッチが確定し、芯が繰り出されて固定される（実物と同じ順序）
- 芯が出ているあいだは**ノックボタンが半分沈んだ位置で止まる**（本物と同じ）
- **半ノック**: ゆっくり押し込むと深さが指に追従し、芯が途中まで出せる（ラッチはしない）
- カムには回転慣性があり、リズムよく連打すると勢いよく回り続ける
- **筆速で線が変わる**: ゆっくり書くと太く濃く、速く書くと細く薄く、さらに速いとかすれる。
  指を止めるとインクだまりがにじんで広がる
- **インクは本当に減る**: 書いた分だけリフィルのインク柱が短くなり、線がかすれ、
  空になると無色のひっかき跡だけに。空のときボディをタップするとリフィル交換
- **紙の手前右の角をスワイプするとページをめくれる**。書いた紙は机の脇に重なって残る

### 🧴 ぽんぷ（石けんポンプの中身）
透明ボトルのソープディスペンサー。押すとピストンがチャンバーを加圧し、
吐出弁のボールが開いてノズルから蜂蜜色の石けんが出て、白い陶器の皿にたまります。
指を離すとバネで戻り、吸入弁のボールが浮いて吸い上げ管から液が補充され、
ボトルの液面が少しずつ下がっていきます。管を液のかたまりがのぼるのも見えます。

- **押す速さ＝圧力**: 速く押すと遠くへ飛び（皿を飛び越すことも）、
  ゆっくり押すとしずくがノズル先にぶら下がってから垂れる。タップは標準の1プッシュ
- 連続で全力ポンプすると**残圧**が乗って1発ごとに強く・泡まじりになる
- 着弾した石けんは**近くの石けんと合体して育ち**、皿がいっぱいになると
  縁からあふれてカウンターへ垂れる。こぼれた液だまりは乾いて色が濃くなって残る
- **皿は指でドラッグして動かせる**（どこで受けるかで結果が変わる）
- 残量が少なくなると吸い上げが遅くなり、管が空気を吸ってスパスパいう。
  ボトルを長押しするとつめかえ（ゴボゴボと気泡がのぼる）

### ☂️ かさ（傘の中身）
ワンタッチ開閉傘。ボタンを押すと透明シャフトの中のバネが伸びてランナーを押し上げ、
8本の骨と受け骨が開いて生地がふわっと張ります（スカラップのたわみ付き）。
雨がアスファルトをだんだん濡らして黒くしていきますが、**開いた傘の下だけは
乾いたまま丸く残ります**。傘は指で傾けられ、乾く場所も動きます。

- **ボタン長押しで手動開閉**: 押している時間ぶんだけゆっくり開き、途中で止められる。
  短いタップは従来どおりバネで一気に開く。半開きでも半径のぶんだけ雨を防げる
- 生地は雨で**濡れが蓄積**し、骨先（ツユ先）から滴が垂れて傘のまわりにリング状の
  濡れ模様が育つ。濡れたまま閉じると溜まった水がバサッとこぼれる
- **横フリックで傘がくるくる回る**（慣性つき）。濡れた生地を回すと遠心力で
  しぶきが螺旋状に飛び、地面に模様を描く
- 濡れが深い場所は**水たまり**になり、雨粒が波紋を立てる（低い水音）
- 突風の強さは毎回違う連続量。**風上へ傾けて構えていれば裏返らない**。
  構えていないと本当に裏返り、生地をタップするとバサッと直る

### 💨 どらいやー（ドライヤーの中身）
半透明ハウジングの中に7枚羽の軸流ファン・モーター・ニクロムヒーターが見えます。
持ち手の上のスイッチで風量（切/弱/強）、下のスイッチで温度（冷/温）を切りかえ。
温風にするとヒーターが赤熱し、空気の流線が青からオレンジに変わります。

- 的がたくさん: リボン（バーレット物理でなびく）・発泡スチロール球（転がる・
  ぶつかり合う）・**紙吹雪14枚**（ひらひら舞って散らばる）・**風車**（風を受けた
  回転が蓄積し、慣性でゆっくり減速。ヒュンヒュン音は回転数連動）・羽根1枚
- **温風は上昇気流**で軽いもの（紙吹雪・羽根）が舞い上がり、冷風は水平に押し流す
- ドラッグ上下=ねらいの角度、**左右=前後の距離**。距離×角度×風量×温度×対象で
  結果が無数に変わる
- ファンには**スプール慣性**があり、スイッチを入れても風はゆっくり立ち上がる。
  スイッチを刻むと風のパルスが作れて、リズムで紙吹雪をあやつれる
- 球は球どうしで弾み、転がって紙吹雪を蹴散らす

### 🎆 はなび（打ち上げ花火の中身）
花火玉に星（色の粒）を自分でトレイからドラッグして詰める → 蓋を閉じて筒へ装填 →
導火線に点火 → 火花が這い進む → 発射 → 上昇 → **自分が詰めた配置どおりに**星が
球状に開きます。玉の端に置いた星は横へ、中心に置いた星は上へ飛ぶので、
詰めかたがそのまま夜空の模様になります。導火線は途中を切って短くでき、
開く高さが変わります。同じ玉は二度と作れません。

### 🚀 ろけっと（ロケットの中身）
断面ロケット。燃料と酸化剤の2本のバルブレバーをアナログに開き、混合比を作ってから
点火ボタン。混合が悪いと点火失敗やスパッタリング、適正なら轟音で上昇します。
上昇中に機体をタップすると段切り離し、高高度でフェアリング展開。空が宇宙の黒に
変わり星が見えます。2本のレバーの開度×点火のタイミング×切り離しのタイミングで
毎回違う飛びかたになります。

### 🚂 きかんしゃ（蒸気機関車の中身）
ボイラーが断面で見えます。石炭をタップでくべる → 火室の火力が上がる →
圧力計がじわじわ上がる → 加減弁レバーを開く → 蒸気がシリンダーへ → ピストンが
動輪を回す。急に全開にすると動輪が空転します。圧力を溜めすぎると安全弁が噴き、
汽笛紐を引くと蒸気を消費して汽笛が鳴ります。くべるリズムと加減弁の開けかたで
景色の流れる速さと煙の量が変わります。

### 🧯 しょうかき（消火器の中身）
まずピンを引き抜き、レバーを握ると、タンクの圧力で粉末が噴射されます。
焚き火の炎は当てた場所だけ消え、当て損ねた熾火から再燃焼が広がります。
圧力計は噴射したぶんだけ本当に減り、使い切ったらタンク交換。マッチで火を
つけ直してもう一度挑戦できます。ねらい×距離×噴射の配分で結果が変わります。

### 🚗 せんしゃき（洗車機の中身）
コインをスロットへドラッグすると、ゲートが上がりコンベアが泥だらけの車を
牽引します。泡アーチ → 回転ブラシ（接触した場所だけ汚れが落ちる）→ すすぎ →
送風乾燥。車はドラッグで前後に動かせるので、ブラシの下に長くとどめると
よく落ち、洗い残しはそのまま残ります。終わったら車をタップで泥道をもう一周。

### 🕹️ くれーん（クレーンゲームの中身）
コインを入れてジョイスティックでガントリーを動かし、ボタンでアームが降下。
3本爪と景品の接触位置で掴みの強さが決まり、搬送中は振り子で揺れて、
掴みが甘いと落ちます。景品の山は掴み損ねるたびに崩れて配置が変わるので、
同じ盤面は二度と来ません。

### 🛗 えれべーたー（エレベーターの中身）
断面ビル4階＋屋上機械室。呼びボタンを押した順に制御盤が記憶し、巻上機の綱車が
回ってロープでカゴが昇降、釣合おもりが逆に動きます。荷物をカゴへドラッグで
積むと重さで速度が落ち、積みすぎるとブザーが鳴って扉が閉まりません。

### 🎫 かいさつ（自動改札機の中身）
切符をスロットへドラッグすると、ローラーが吸い込み、断面の中をベルトが高速搬送。
途中で切符がくるっと裏返って向きが揃い、スタンプがガチャンと日付を打ち、
出口から飛び出してフラップが開きます。連続投入すると中で切符が追いかけっこ。
期限切れの切符（赤いほう）は途中で止まって警告音、逆走して突き返されます。

### 🔐 きんこ（銀行の金庫ダイヤルの中身）
断面ダイヤル錠。ダイヤルを回すとドライブピンが3枚のタンブラー円盤を
1枚ずつ拾って回します（実物と同じピン拾い機構）。切り欠きが上に揃うのが断面で
見えるので、目で見ながら「奥の円盤→まん中→手前」の順に揃えます。全部揃うと
フェンスがカチャンと落ち、ハンドルが回せるようになり、リンク機構でボルト4本が
引けて、重い扉がゆっくり開きます。中には金塊。回しすぎたらやり直し。
組合せは毎回変わります。

### 📷 かめら（フィルム一眼レフの中身）
断面一眼レフ。巻き上げレバーを引くとスプロケットが回ってフィルムが1コマ送られ、
シャッターがチャージされます。シャッターボタンでミラーが跳ね上がり幕が走って、
**そのしゅんかんの景色が本当にフィルムに写ります**（風車と鳥が動いています）。
シャッター速度ダイヤルで 1/30〜1/500 を選べて、速いと動きが止まり暗く、
遅いと流れて明るく写ります。カメラはドラッグで構図を変えられます。
8枚撮り切ったら巻き戻しクランクを回すと現像がはじまり、撮った写真がプリントに
なって机にならびます。同じ写真は二度と撮れません。

## 技術メモ

- 3D描画は同梱の Three.js r147（UMDビルド）。npm等のビルド工程は不要で、
  `file://` 直開きでも静的ホスティングでも動きます。
- 質感は物理ベースレンダリング：透明部品は `transmission`（実屈折）+ clearcoat、
  金属はPBR、環境マップは同梱 RoomEnvironment の PMREM 化（外部HDRファイル不要）。
  ACESトーンマッピング + sRGB出力 + ソフトシャドウ。
  ※ three.js の transmission パスは他の透過マテリアルを映さないため、
  透明容器の中に入る部品は不透明素材で作っています。
- バネはヘリックス曲線からの実ジオメトリで、圧縮するとピッチが縮みます
  （ペンのノック・ポンプのチャンバー・傘のシャフト内で共通利用）。
- ペンの筆記は紙メッシュへのレイキャストで、CanvasTexture に直接インクを描画。
- 傘の生地はパラメトリック曲面（8セクター、開閉角で変形）、雨は Points、
  地面の濡れは CanvasTexture への描き込みで表現（ゆっくり乾く）。
- ドライヤーの空気は InstancedMesh の流線パーティクル、リボンはバーレット物理、
  球は簡易剛体（風力・重力・反発・転がり）。
- 効果音はすべて Web Audio API で合成（音声ファイルなし）：
  金属ラッチのクリック・バネ残響・筆記摩擦・ポンプのスクイズ・ゴボッという吸い上げ・
  雨の環境音・ファンのうなり・布のはためき・導火線のシュー・打ち上げのドン・
  汽笛・改札のスタンプ・シャッター幕・コイン投入・金庫のカチャン等。
- 花火の星・火の粉・煙・水しぶきは InstancedMesh の粒子群。
- カメラの撮影は本物: 撮影用カメラで WebGLRenderTarget にレンダリングし、
  `readRenderTargetPixels` で読み出して Canvas に焼き、プリントのテクスチャに
  しています。遅いシャッターは複数サブフレームの合成で本当にブレます。
- 金庫のダイヤル錠はピン拾い（ドライブピンの遊びがほぼ1回転ある）を
  連続角のクランプで実装した実機構シミュレーションです。
- iPad実機負荷を考慮し、pixelRatio上限2・transmissionは外殻のみに限定。
