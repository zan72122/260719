# スケスケなかみランド

スケスケ断面の日用品を、指でいじって動かす4歳向けのタッチゲーム集です。
「見えない場所で何かが動いて、それが外の結果に変わる」瞬間を楽しむ遊びです。

- 正確な機械構造 30%、かわいい因果の見える化 70%
- 歯車もバネも本物より大きく、弁は色つき、空気は小さな丸、水はキラキラ
- 詰まりや失敗は笑いに、音は大げさに（Web Audioで合成）

## あそびかた

`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部依存なし・オフラインOK）。
iPad / iPhone の Safari、縦画面・横画面のどちらでも遊べます。
GitHub Pages などの静的ホスティングにそのまま置いても動きます。

## 収録ミニゲーム

### 🖊️ ぺん（ノック式ボールペンの中身）
上の赤いボタンをノックすると、中でバネがびよん、ピンクの爪がカチッ、芯がスッと出ます。
芯が出ているあいだは、右の紙に指でおえかきできます（色は押すたびに変わる）。
連打するとペンが照れてぶるぶる震え、インク玉が目を回します。

### 🧴 ぽんぷ（石けんポンプの中身）
ヘッドを押すと、ピストンが下がり、緑の弁がパカッと開いて石けんが飛び、
手についた泥よごれがきれいになります。指をはなすと赤いボール弁が浮いて、
キラキラが管をのぼって液を吸い上げます。
「さらさら / とろとろ / あわあわ」の切りかえで、出かたの速さと形が変わります。
泡を山盛りにするとぶるぶる震えて、ポンッとはじけます。ボトルが空になったら
🫗ボタンでつめかえ。

### ☂️ かさ（傘の中身）
赤いボタンを押すと、棒の中のバネがランナーを押し上げ、骨がふわっと開いて
雨粒がころころ転がり落ちます。傘は指でかたむけられます。
雲をタップすると突風が吹いて傘が裏返り（笑いどころ）、傘をタップすると
びよんと直ります。下のひよこは、傘がないと濡れてぷるぷるします。

### 💨 どらいやー（ドライヤーの中身）
スイッチを入れると中のファンが回り、空気の小さな丸が流れていきます。
「あったかい」にするとヒーターが光って風がオレンジ色に。
風のむきは指で上下にうごかせて、女の子の髪とリボンがなびき、
シャボン玉が飛ばされます（つついてもパチンと割れる）。
「つよい×あったかい」を続けると髪がボワッと爆発ヘアーになります。

## フォルダ構成

```
sukesuke-lab/
├── index.html      # エントリーポイント（ホーム画面）
├── css/
│   └── style.css   # 見た目（縦横対応・ホーム画面）
└── js/
    ├── util.js     # SVGヘルパー・バネ物理・エフェクト
    ├── sound.js    # Web Audioによる効果音の合成
    ├── main.js     # 画面切りかえ
    ├── pen.js      # ボールペン
    ├── pump.js     # 石けんポンプ
    ├── umbrella.js # 傘
    └── dryer.js    # ドライヤー
```

## 技術メモ

- 依存ライブラリなし。SVG + requestAnimationFrame で描画し、
  ばね物理（減衰バネ）で「びよんびよん」を表現しています。
- 効果音はすべて Web Audio API のオシレーター＋ノイズで合成
  （カチッ・びよ〜ん・ポンッ・キラキラ・風の音など）。音声ファイルはありません。
- viewBox によるスケーリングで、縦画面・横画面のどちらでも同じ内容が収まります。
- マルチタッチ対応（例：片方の指でノックしながら、もう片方でおえかき）。
