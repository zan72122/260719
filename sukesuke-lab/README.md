# スケスケなかみランド

スケスケ断面の日用品を、指でいじって動かす4歳向けのタッチゲーム集です。
「見えない場所で何かが動いて、それが外の結果に変わる」瞬間を楽しむ遊びです。

方針: **写実3D**。実在の道具をマクロ撮影したような画づくりと、実物準拠の機構。
4ゲームすべて Three.js による WebGL 描画です。

## あそびかた

`index.html` をブラウザで開くだけで遊べます（ビルド不要・オフラインOK・Three.js同梱）。
iPad / iPhone の Safari、縦画面・横画面のどちらでも遊べます。
GitHub Pages などの静的ホスティングにそのまま置いても動きます。
どのゲームも、何もない場所をドラッグすると視点を回して機構を観察できます。

## 収録ミニゲーム

### 🖊️ ぺん（ノック式ボールペンの中身）
実在の透明軸ノック式ボールペンを再現。屈折する透明ボディの中に、
バネ鋼のコイル・回転カム式ラッチ・真鍮のペン先・インク入りリフィルが見えます。

- 紺色ボタンを押す → バネが圧縮 → 最下点でカムが1歯回って「カチッ」
  → 指を離すと戻り行程でラッチが確定し、芯が繰り出されて固定される（実物と同じ順序）
- 芯が出ているあいだは**ノックボタンが半分沈んだ位置で止まる**（本物と同じ）
- もう一度ノックするとカムが滑ってバネが芯をはね戻す（金属の微振動音つき）
- 芯が出ているあいだ、机のメモ用紙を指でなぞると本当にボールペンの線が書ける
  （速く書くと線がわずかに細くなる・紙をこする摩擦音つき）

### 🧴 ぽんぷ（石けんポンプの中身）
透明ボトルのソープディスペンサー。押すとピストンがチャンバーを加圧し、
吐出弁のボールが開いてノズルから蜂蜜色の石けんが出て、白い陶器の皿にたまります。
指を離すとバネで戻り、吸入弁のボールが浮いて吸い上げ管から液が補充され、
ボトルの液面が少しずつ下がっていきます。管を液のかたまりがのぼるのも見えます。

### ☂️ かさ（傘の中身）
ワンタッチ開閉傘。ボタンを押すと透明シャフトの中のバネが伸びてランナーを押し上げ、
8本の骨と受け骨が開いて生地がふわっと張ります（スカラップのたわみ付き）。
雨がアスファルトをだんだん濡らして黒くしていきますが、**開いた傘の下だけは
乾いたまま丸く残ります**。傘は指で傾けられ、乾く場所も動きます。
ときどき突風が吹いて傘が本当に裏返り、生地をタップするとバサッと直ります。

### 💨 どらいやー（ドライヤーの中身）
半透明ハウジングの中に7枚羽の軸流ファン・モーター・ニクロムヒーターが見えます。
持ち手の上のスイッチで風量（切/弱/強）、下のスイッチで温度（冷/温）を切りかえ。
温風にするとヒーターが赤熱し、空気の流線が青からオレンジに変わります。
風はスタンドに掛かったリボンをなびかせ、軽い発泡スチロール球を吹き飛ばします。
ドライヤーは指で上下にねらいを変えられます。

```
    ├── util.js           # バネ物理などの共通ヘルパー

    ├── umbrella.js       # 傘 (写実3D)
    └── dryer.js          # ドライヤー (写実3D)
```

## 技術メモ

- 3D描画は同梱の Three.js r147（UMDビルド）。npm等のビルド工程は不要で、
  `file://` 直開きでも静的ホスティングでも動きます。
- 質感は物理ベースレンダリング：透明部品は `transmission`（実屈折）+ clearcoat、
  金属はPBR、環境マップは同梱 RoomEnvironment の PMREM 化（外部HDRファイル不要）。
  ACESトーンマッピング + sRGB出力 + ソフトシャドウ。
  ※ three.js の transmission パスは他の透過マテリアルを映さないため、
  透明容器の中に入る部品は不透明素材で作っています。
- バネはヘリックス曲線からの実ジオメトリで、圧縮するとピッチが縮みます
  （ペンのノック・ポンプのチャンバー・傘のシャフト内で共通利用）。
- ペンの筆記は紙メッシュへのレイキャストで、CanvasTexture に直接インクを描画。
- 傘の生地はパラメトリック曲面（8セクター、開閉角で変形）、雨は Points、
  地面の濡れは CanvasTexture への描き込みで表現（ゆっくり乾く）。
- ドライヤーの空気は InstancedMesh の流線パーティクル、リボンはバーレット物理、
  球は簡易剛体（風力・重力・反発・転がり）。
- 効果音はすべて Web Audio API で合成（音声ファイルなし）：
  金属ラッチのクリック・バネ残響・筆記摩擦・ポンプのスクイズ・ゴボッという吸い上げ・
  雨の環境音・ファンのうなり・布のはためき等。
- iPad実機負荷を考慮し、pixelRatio上限2・transmissionは外殻のみに限定。
