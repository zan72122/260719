# スケスケなかみランド

スケスケ断面の日用品を、指でいじって動かす4歳向けのタッチゲーム集です。
「見えない場所で何かが動いて、それが外の結果に変わる」瞬間を楽しむ遊びです。

方針: **写実3D**。実在の道具をマクロ撮影したような画づくりと、実物準拠の機構を目指します
（ボールペンから順次3D化中。ポンプ・傘・ドライヤーは旧2D版のまま、確認後に展開予定）。

## あそびかた

`index.html` をブラウザで開くだけで遊べます（ビルド不要・オフラインOK・Three.js同梱）。
iPad / iPhone の Safari、縦画面・横画面のどちらでも遊べます。
GitHub Pages などの静的ホスティングにそのまま置いても動きます。

## 収録ミニゲーム

### 🖊️ ぺん（ノック式ボールペンの中身）— 写実3D版
実在の透明軸ノック式ボールペンをWebGLで再現。屈折する透明ボディの中に、
バネ鋼のコイル・回転カム式ラッチ・真鍮のペン先・インク入りリフィルが見えます。

- 上の紺色ボタンを押す → バネが実挙動で圧縮 → 最下点でカムが1歯回って「カチッ」
  → 指を離すと戻り行程でラッチが確定し、芯が繰り出されて固定される（実物と同じ順序）
- もう一度ノックするとカムが滑ってバネが芯をはね戻す（金属の微振動音つき）
- 芯が出ているあいだ、机のメモ用紙を指でなぞると本当にボールペンの線が書ける
  （速く書くと線がわずかに細くなる・紙をこする摩擦音つき）
- 何もない場所をドラッグすると視点を回して機構を観察できる
- 音は効果音ファイルなしのWeb Audio合成（金属ラッチのクリック・バネの残響・筆記音）

### 🧴 ぽんぷ（石けんポンプの中身）
ヘッドを押すと、ピストンが下がり、緑の弁がパカッと開いて石けんが飛び、
手についた泥よごれがきれいになります。指をはなすと赤いボール弁が浮いて、
キラキラが管をのぼって液を吸い上げます。
「さらさら / とろとろ / あわあわ」の切りかえで、出かたの速さと形が変わります。
泡を山盛りにするとぶるぶる震えて、ポンッとはじけます。ボトルが空になったら
🫗ボタンでつめかえ。

### ☂️ かさ（傘の中身）
赤いボタンを押すと、棒の中のバネがランナーを押し上げ、骨がふわっと開いて
雨粒がころころ転がり落ちます。傘は指でかたむけられます。
雲をタップすると突風が吹いて傘が裏返り（笑いどころ）、傘をタップすると
びよんと直ります。下のひよこは、傘がないと濡れてぷるぷるします。

### 💨 どらいやー（ドライヤーの中身）
スイッチを入れると中のファンが回り、空気の小さな丸が流れていきます。
「あったかい」にするとヒーターが光って風がオレンジ色に。
風のむきは指で上下にうごかせて、女の子の髪とリボンがなびき、
シャボン玉が飛ばされます（つついてもパチンと割れる）。
「つよい×あったかい」を続けると髪がボワッと爆発ヘアーになります。

## 技術メモ

- 3D描画は同梱の Three.js r147（UMDビルド）。npm等のビルド工程は不要で、
  `file://` 直開きでも静的ホスティングでも動きます。
- ペンの質感は物理ベースレンダリング：
  透明ボディは `transmission`（実屈折）+ clearcoat、バネ・ペン先・リングは金属PBR、
  環境マップは同梱 RoomEnvironment を PMREM 化（外部HDRファイル不要）。
  ACESトーンマッピング + sRGB出力 + ソフトシャドウ。
- バネはヘリックス曲線からの実ジオメトリで、圧縮するとピッチが縮みます。
- 筆記は紙メッシュへのレイキャストで、CanvasTexture に直接インクを描画。
- 効果音はすべて Web Audio API で合成（音声ファイルなし）。
  写実系（金属クリック・バネ残響・筆記摩擦音）と旧2Dゲーム用カートゥーン系を併載。
- iPad実機負荷を考慮し、pixelRatio上限2・transmissionは透明ボディのみに限定。
