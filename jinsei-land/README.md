## あそびかた

1. `index.html` をブラウザで開く（iPhone / iPad の Safari 推奨。「ホーム画面に追加」するとフルスクリーンで遊べます）
2. どうぶつ（🐰うさぎ・🐻くま・🐱ねこ・🐼ぱんだ）をえらぶ
3. あそびかたをえらぶ
   - 🚗 **ひとりで** … のんびりゴールをめざす
   - 🤖 **ともだちと** … コンピュータのどうぶつと交互に遊ぶ
   - 👦👧 **ふたりで** … 1台をふたりで交代しながら遊ぶ
4. 「🎲 しゅっぱーつ！」→ ルーレットをタッチ（またはビュンとはじく）→ くるまがぴょんぴょん進む！

文字が読めなくても遊べるように、すべての指示は **アイコン＋アニメ＋音声（Web Speech）** で伝えます。

### 👶→👴 せいちょうステージ（コース＝じんせい）
4つのくにが人生の4ステージに対応。ゾーンの境界にある**きらきらゲート**をくぐると
「あかちゃん（ボンネット）→ こども（赤いぼうし）→ おとな（シルクハット）→ おじいちゃん（白ひげ＋めがね）」
と**衣装と頭の大きさが変わる**。

### 💼 おしごとマス
おしごとカードが頭上をぐるぐる回って、止まったところで職業が決定
（🚒しょうぼうし・🍰ケーキやさん・🚀うちゅうひこうし・👮おまわりさん・🎨がかさん）。
**職業の帽子をかぶり**、毎ターン「おきゅうりょう ⭐+1」がもらえる。

### 🛒 おかいものマス（ほしの使い道！）
おみせが開いて、ためたほしでお買い物。
- 日常のもの … 🍦アイス・🧸ぬいぐるみ・⚽ボール →**車の荷台に積まれて見える**
- 非日常のもの … 🚁ヘリコプター（その場で4マス空の旅）・🐘ぞうさん・🏠おうち・🏰**ごうてい**（ゴール横に本当に建つ！カメラが見に行く）
- 買えるものがない時は店員さんの「おまけ ⭐+1」（泣かない設計）

### 💒 けっこん・🍼 あかちゃんマス
パートナーがベールをつけて駆けてきて**車に同乗**。たまごから赤ちゃんも誕生。
家族が増えるとゴールで**かぞくボーナス**（1人につき⭐+2）。おうち購入者には**おうちボーナス**も。

### ⛈ あめあめマイナスルーレット
雷雲がやってきて、ルーレットが**まっ青な −1〜−6 モード**に変身（ドキドキ！）。
バックする途中で**ともだちどうぶつが飛び出して止めてくれる**ことも。
最後は必ず晴れてミニ虹＋なぐさめの⭐+1で笑って終わる。

### 🕳 おおあなマス
床にストンと落ちると、そこは**光るキノコと水晶のひみつのどうくつ**！
とびいしをぴょんぴょん渡って宝箱（⭐+3）を開け、**間欠泉でぴゅーんと地上へ**打ち上げられて2マス先に復帰。

### 🎢 ジェットコースターマス
コースに実在する**赤いレールの絶叫マシン**に乗車。カメラも後ろにぴったり張り付く追走視点で、
悲鳴と風の音とともに5マスぶんを一気に駆け抜ける（降りたら⭐+2）。

### 🌪 たつまきマス
竜巻に巻き上げられて宙づりに！**エメラルド色の「どこにとぶ！？」ルーレット**で行き先が決まる。
着地先は必ずたのしいマスに補正され、ご近所さんが「ようこそ〜！」とお出迎え。

### 🐭 どろぼうねずみ（ランダムイベント）
たまに現れてほしを2個持ち逃げ…でも**3マス先で必ずすってんころりん**、ほしが3個に増えてこぼれ落ちる（net +1）。
逃げている途中に**タッチすると即転ばせられる**。

## フォルダ構成

```
jinsei-land/
├── index.html        画面とUI
├── css/style.css     タイトル・HUD・けっか画面のスタイル
├── js/
│   ├── main.js       画面の切りかえ・キャラ選択
│   ├── game.js       ターン制御・カメラ・マスイベント
│   ├── world.js      コース・4つのくに・かざり
│   ├── characters.js くるま・どうぶつ・おうえんだん
│   ├── roulette.js   ルーレット（Canvas 2D）
│   ├── effects.js    パーティクル・紙吹雪・花火
│   ├── sound.js      効果音・BGM・音声（全部 Web Audio 合成）
│   └── util.js       小道具
├── vendor/three.min.js  Three.js r147（同梱・オフラインOK）
└── assets/           スクリーンショット
```

## 技術メモ

- Three.js（同梱）のみ使用。ビルド不要・完全オフラインで動作
- 音はすべて Web Audio API でリアルタイム合成（音声ファイルなし）
- iOS対応：`viewport-fit=cover`・safe-area・タッチ音声アンロック・ダブルタップ拡大防止
- 縦横どちらでもOK：向きに応じてカメラの高さ・FOV・UIレイアウトを自動調整
- 低負荷設計：ブロブシャドウ（影マップなし）・ジオメトリ使い回し・パーティクルは寿命管理
