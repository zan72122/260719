# ABCコースター 🎢 — もじのかたちを のりこなせ!

**アルファベットの一筆書きの線が、そのままジェットコースターのレールになる**ゲームです。
[supertype](https://play.google.com/store/apps/details?id=de.kamibox.typo) の「文字＝物理オブジェクト」の哲学を、
「乗る・つなぐ・予測する」遊びに翻案しました。4歳の英語学習者向けです。

> 遊びの主動作が字形の一筆書きそのものと一致しているので、
> 「形をそのまま使う」「ゲームとして楽しい」「自然に形を意識する」が分離せず一体になります。

## あそびかた

iPhone / iPad の Safari で `index.html` を開くだけ。縦・横どちらの画面でも遊べます。
(共有メニュー →「ホーム画面に追加」でフルスクリーンのアプリになります)

ローカルで試すなら:

```bash
cd abc-coaster
python3 -m http.server 8000
# → http://localhost:8000
```

音声は端末内蔵の英語TTS (Web Speech API)。ネット接続・外部ライブラリ・ビルドすべて不要です。

## 🎢 メイン: ABCコースター

駅に着くたびに、子どもが次の文字を3択から選んでコースをつなげます。
選んだ文字の**書き順の線の上を**ウサギのトロッコが走ります。

| 文字 | 乗り心地 |
|---|---|
| **O・Q** | 完全一回転ループ! (Qは尻尾のスロープから退場) |
| **W** | 二段谷。**M** は二連山 |
| **U** | 大きな谷底で最高速に |
| **Z** | 2回のヘアピンで逆走ダウンヒル |
| **H** | 2本の塔をスイッチバック |
| **G** | 内側の棚が行き止まり → バンパーに当たって跳ね返る |
| **J** | フックの先から空へ発射、次の文字までジャンプ! |
| **I** | ただの一直線の大落下 (それがIのすべて) |

- レールの下には**同じ形の太い半透明の文字**が敷かれ、「レール＝文字の形」が一目でつながる
- 文字に入る瞬間に英語で名前を発音。登り坂は「ガタン、ガタン」、頂上で「フワッ」、急降下で「ヒュー!」
- 走らない画数 (Aの横棒、Tの横棒の半分など) は**鉄骨**として描かれ、文字の見た目を完成させる
- レール上の星を集める。5文字つなぐごとに花火

**選ぶ瞬間に「この形はどんな動きになる?」と字形を目でなぞって予測すること**が、このゲームの学習の芯です。

## 🎈 ミニゲーム1: ふうせんもじ (位相 = 閉じてる?開いてる?)

「この文字、ふくらませたら **とぶ? もれる?**」を予想してからポンプを4回。

- **輪が閉じた文字 (A B D O P Q R)** → 穴がピンクの風船になってふくらみ、ウサギのかごを乗せて空へ!
- **開いた文字 (C E F …)** → すきまから「プスー!」と漏れ、手を離した風船みたいに暴れ回ってペチャンコに
- 漏れた場所 (= 文字のすきま) を赤い丸で指し示す → **C と O の違いは「あの隙間」だと体で分かる**

## 🎪 ミニゲーム2: さかさまサーカス (対称 = 回っても同じ?)

ブランコの文字が宙返り。「くるっと回ったら、だれになる?」を2択で予想。

- **N・S・Z・O・H・I・X** は回っても同じ「さかさまチャンピオン」
- **M↔W、b↔q、d↔p、u↔n** は回ると別人に変身! (幼児最大の壁 b/d/p/q の混同に正面から効く)
- 正解発表のあとは指でぐるぐる自由に回して確かめられる (180°ごとにスナップ)

## 🍪 ミニゲーム3: もじクッキーやさん (差分 = あの1本・あの隙間)

お客のモンスターが英語で注文:「**C, please!**」— でも棚にあるのは O のクッキーだけ。

- **多すぎる** → 🦷 かじって減らす: O をひとくち→C、R の足→P、Q のしっぽ→O、E の下の棒→F、B の下のこぶ→P、P のこぶ→I
- **足りない** → 🍫 チョコペンで描き足す: C＋横棒→G、P＋足→R、F＋下の棒→E、O＋しっぽ→Q、I＋上の棒→T、C の口を閉じて→O
- 道具の選択自体がクイズ:「注文の文字は、今あるクッキーより**多い? 少ない?**」— 間違えると英語でヒント ("It's too big! Bite it!")
- かじる場所を自分で見つけてタップ (迷ったら赤い輪のヒント)、チョコペンは点線ガイドをなぞって描く
- できたクッキーはモンスターの口へ飛んでいき、3口でバリバリ完食。「Yum yum! C! Thank you!」
- モンスターをタップすると注文をもう一回言ってくれる (リスニング練習)

**文字どうしの「差分」= 識別ポイントだけを教材化した、まちがい探しの逆再生**です。
同じペアが両方向で出る (O→C はかじる、C→O は描く) ので、差分が双方向で定着します。

## 3条件の対応表

| 条件 | コースター | ふうせん | サーカス | クッキー |
|---|---|---|---|---|
| 1. 形をそのまま利用 | 一筆書きの線＝レール | 閉じた輪＝風船, すきま＝漏れ口 | 字形の点対称性そのもの | 画数の差分＝かじる/描く場所 |
| 2. ゲームとして楽しい | ループ・落下・発射・星集め | 予想→ポンプ連打→大騒ぎ | 予想→ドラムロール→宙返り | お店ごっこ・かじる爽快感 |
| 3. 自然に形を意識 | 選ぶ前に軌道を目でなぞる | 隙間の位置に注目が集まる | 回転後の形を頭の中で組み立てる | 2文字の違いを探して指す |

字形の4つの本質 — **軌道 (どう繋がる線か)・位相 (閉じているか)・対称 (回すとどうなるか)・差分 (どこが違うか)** — を1本でカバーします。

## 技術メモ

- 依存ゼロ (物理エンジン不使用)。レールは折れ線の弧長パラメータ化で、坂の勾配から速度を積分
- 登り坂では止まらないようチェーンリフトが押す (最低速度保証) — 4歳に「詰み」はない
- 効果音は全てWebAudioで合成 (重さ・速度連動)。iOSの自動再生制約は初回タップでアンロック
- `viewport-fit=cover` + `safe-area-inset` でノッチ端末対応、縦横回転対応
