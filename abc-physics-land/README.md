# ABC Land — もじの物理あそび 🎪

[supertype](https://play.google.com/store/apps/details?id=de.kamibox.typo) 風の
「**文字＝さわれる物理オブジェクト**」ゲームです。
英語を1年学んでマンネリ気味の4歳児が、アルファベットそのものと友だちになり直すための遊び場です。

> How does a p fall? — P はコロンと前のめりに倒れます
> How much does an r weigh? — W は I の3倍以上重く、落ちると低い「ドスン」
> And how does the dot over an i sound? — i の点ははずれて転がり、鈴の音を鳴らします 🔔

## あそびかた

iPhone / iPad の Safari で `index.html` を開くだけ。縦画面でも横画面でも遊べます。
(共有メニュー →「ホーム画面に追加」でフルスクリーンのアプリになります)

ローカルで試すなら:

```bash
cd abc-physics-land
python3 -m http.server 8000
# → http://localhost:8000
```

※ 音声はすべて端末内蔵の英語TTS (Web Speech API) なので、ネット接続もアプリも不要です。

## 3つのモード

| モード | 内容 |
|---|---|
| 🎪 **PLAY もじあそび** | 下のトレイから文字を選んで降らせる物理砂場。文字をタップすると英語で「B! buh… Ball!」としゃべり、絵文字が飛び出す。`Aa` で大文字/小文字切替、🌙 で月面重力(みんなふわふわ！)、🧹 でおそうじ |
| 🧩 **WORDS ことばパズル** | CAT・DOG・BUS… 文字をドラッグして枠にはめると単語が完成。完成すると英語で「C-A-T… Cat!」と読み上げ、その絵文字が雨のように降ってくる |
| ⭐ **FIND もじキャッチ** | 「Find the letter… B!」と耳で聞いて、ふわふわ降ってくる文字の中から正解をタップ。5個キャッチで花火! まちがえても文字が名前を言って跳ねるだけ (罰なし) |

## 文字の「個性」(supertype の心臓部)

全26文字が形・重さ・音・動きを持つ物理キャラクターです。

- **形**: C・G・O・Q はまんまるで転がる / A は三角でどっしり / V は逆三角でコロンと倒れる / T・L は棒の組み合わせ / **U はコップ型で、他の文字を受け止められる**
- **重さ**: インクの量で決定。I は軽く、W・M は重い。衝突音の高さも重さで変わる (軽い字=コツン、重い字=ドスン)
- **動き**: F は羽のようにふわふわ落ちる / Z はジグザグに落ちる / S・B は超はずんで「ボヨン」/ 小文字の i・j は**点がはずれて別々に落ち、当たると鈴の音**
- **顔**: 全文字にまばたきする目と、指を目で追う瞳。ぶつかると「むにっ」とつぶれる
- **声**: タップすると 名前 → フォニックス → 代表単語 (A→Apple🍎 … Z→Zebra🦓) を英語で発話

## フォルダ構成

```
abc-physics-land/
├── index.html          エントリポイント
├── css/style.css       UI (4歳の指のための大きなボタン)
├── js/
│   ├── letters.js      26文字の個性データ + 単語リスト
│   ├── sound.js        WebAudio効果音シンセ + 英語TTS
│   ├── fx.js           紙吹雪・星・絵文字・花火パーティクル
│   ├── physics.js      Matter.js の世界と文字ボディ工場
│   ├── render.js       顔つき文字の描画・空と月の背景
│   ├── modes.js        3モードのゲームロジック
│   └── main.js         起動・入力・メインループ
├── vendor/matter.min.js  Matter.js 0.19.0 (物理エンジン, MIT)
└── assets/icon.png     ホーム画面用アイコン
```

## 技術メモ

- 依存は同梱の Matter.js のみ。ビルド不要・完全オフライン動作
- マルチタッチ対応 (2本の指で2つの文字を同時にドラッグできます)
- 音声・効果音は iOS の制約に合わせて最初のタップでアンロック
- `viewport-fit=cover` + `safe-area-inset` でノッチ端末にも対応
