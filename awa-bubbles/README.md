# あわあわバブルス 〜ぷちぷち泡クラスターパズル〜

Tiny Bubbles にインスパイアされた、泡クラスター物理パズルゲームです。
iPhone / iPad の縦画面・横画面のどちらでも遊べます（PCブラウザでもマウスで遊べます）。

`index.html` をブラウザで開くだけで動きます（ビルド不要・依存ライブラリなし・完全オフライン動作）。

## あそびかた

- **ながおし**：泡に色つきの空気を吹き込んでふくらませる。まわりの泡を押しのける
- **あいた場所をながおし**：あたらしい泡がうまれる
- **同じ色が4こ**くっつくと ぽん！と割れる
- ちがう色を吹き込むと**混色**（あか＋きいろ＝オレンジ、きいろ＋あお＝みどり、あか＋あお＝むらさき）
- ふくらませすぎると**泡のかべが破れて合体**し、色がまざる（空気の一部は逃げる）
- 3色まぜすぎると**にごり泡**に。ひとつの色をたっぷり足せば復活
- れんぞくで割ると**チェイン**。3チェイン or 8こ同時割りで**ワイルド泡**（万能色）出現
- 泡にとらわれた**いきもの**は泡を割って救出。**ウニ**と**ジェリーカニ**は泡を割ってしまう敵

## モード

| モード | 内容 |
|---|---|
| 🧩 パズル | 手づくり40レベル×4ワールド。限られた空気で目標達成。パー以内クリアで★3 |
| 🔥 アーケード | 湧き続ける泡をさばくスコアアタック。あふれたら終了。ウニの乱入あり |
| 🌊 むげん | 制限なしのリラックスモード。全色＋ワイルドを自由に使える |

そのほか：**じっせき35種**、通算きろく、ヒント機能、好奇心旺盛な魚「ブループ」のおしゃべり、手続き生成のアンビエントBGMと泡サウンド（WebAudio）、実績・進捗のローカルセーブ。

## 技術メモ

- **物理エンジン**（`js/physics.js`）：Verlet積分＋位置ベース拘束（PBD）の自作「分子動力学風」エンジン。押し合い・表面張力（凝集）・浮力・水の粘性・障害物・破裂衝撃波を再現。空間ハッシュで数百個の泡を60FPSで処理
- **フォーム描画**（`js/render.js`）：泡は円として計算し、描画時に隣接泡とのパワー図（加重ボロノイ）平面で輪郭をクリップ→スムージング。本物の泡クラスターのような平らな共有壁・プラトー境界・ぷるぷる変形を表現
- **混色システム**（`js/util.js`）：各泡が三原色の体積比を保持し、注入・合体で連続的に混合。比率から表示色クラス（原色/二次色/にごり）を分類
- **サウンド**（`js/audio.js`）：全て WebAudio でリアルタイム生成。パッド和音＋ペンタトニックの水琴、泡の大きさでピッチが変わるポップ音、チェインで音階上昇
- **入力**：Pointer Events によるマルチタッチ対応（2本指で同時に別の泡を吹ける）。セーフエリア対応、画面回転対応、重い端末では自動で描画品質を調整

## ファイル構成

```
awa-bubbles/
├── index.html          エントリポイント
├── css/style.css       UIスタイル（縦横レイアウト対応）
└── js/
    ├── util.js         数学ユーティリティ・色システム
    ├── physics.js      泡物理エンジン
    ├── render.js       フォームレンダラー・背景
    ├── fx.js           パーティクル・浮遊テキスト
    ├── audio.js        手続き生成サウンド
    ├── creatures.js    いきもの（プチリン・ウニ・カニ・ブループ）
    ├── levels.js       パズル40レベル定義
    ├── achievements.js 実績35種・セーブデータ
    ├── game.js         ゲームロジック（マッチ・チェイン・モード）
    ├── ui.js           画面・HUD・モーダル
    └── main.js         起動・メインループ・入力
```
