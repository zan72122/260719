# ちょきちょきのき

[Prune](https://store.steampowered.com/app/3903490/Prune/) 風の
「木をそだてて、いらない枝を切って、花をさかせる」ゲームです。
4歳児が iPhone / iPad（縦画面・横画面どちらでも）で遊ぶことを想定しています。

## あそびかた

`index.html` をブラウザで開くだけで遊べます（ビルド不要・オフラインOK・外部ライブラリなし）。
GitHub Pages などの静的ホスティングにそのまま置いても動きます。

1. **たねをタップ** → 木がひとりでにぐんぐんのびて、枝分かれしていく
2. **えだを指でなぞる** → 「ちょきん！」と切れて、切った枝はひらひら落ちていく
3. 木の先っぽが **太陽のひかりの輪** に入ると 🌸 花がさく
4. 画面上のめあて（🌸の数）まで花がさいたらクリア！つぎのレベルへ

### ちょきちょきのコツ

- 枝を切ると、切り株からしばらくして **太陽のほうへ新しい芽** が出ます。
  「いらない枝を切る → のこりが太陽へむかう」のがこのゲームの気持ちいいところ
- **灰色の雲** のかげに入った枝はしょんぼりして止まってしまうので、切ってあげよう
- 切りすぎても大丈夫。木の元気はゆっくり回復するし、負けや失敗はありません

## 4歳児むけの工夫

- 文字はぜんぶひらがな。操作は「タップ」と「なぞる」の2つだけ
- 負け・失敗・時間制限なし。詰んでも切れば新しい芽が出る救済つき
- 迷っていると 👆 のゆびアニメが「たっぷしてね」「なぞってちょきちょき」と教えてくれる
- 当たり判定は指サイズに大きめ。マルチタッチ対応（両手でちょきちょきしてOK）
- ボタンは大きめ（44px以上）、誤操作しやすい位置を避けて配置
- 効果音はぜんぶ WebAudio でやわらかく合成（ちょきん・ぽん・ペンタトニックの花の音）

## レベル

全10レベル。太陽の位置・雲のじゃま・さかせる花の数がすこしずつ変わり、
レベルごとに空の色（あさ・ゆうやけ・よる・ゆき・ほしぞら…）も変わります。
クリアしたところまで保存され（localStorage）、タイトルのばんごうから選べます。

## しくみ（技術メモ）

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み（タイトル・ゲーム・クリアの3画面） |
| `css/style.css` | UI・ヒント・アニメーション |
| `js/levels.js` | レベル定義とカラーパレット（位置はすべて相対座標） |
| `js/tree.js` | 木の成長・分岐・剪定・切り株からの再生モデル |
| `js/sound.js` | WebAudio による効果音の合成 |
| `js/main.js` | 描画・入力・パーティクル・画面遷移 |

- 描画は Canvas 2D。座標はすべて画面サイズからの相対値で計算しているので、
  縦画面・横画面・回転にそのまま追従します（回転時は木の形も相似変形）
- 木は「枝＝点列」の集まり。先端がエネルギーを消費しながらのびて分岐し、
  切るとエネルギーの一部が戻る＋切り株から太陽方向に新芽が出る、という
  Prune のプルーニング（間引くほど残りが伸びる）の簡略版
- 音声・画像アセットは一切なし（すべてプロシージャル生成）
