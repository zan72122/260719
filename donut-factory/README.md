# ドーナツこうじょう 🍩

[Freshly Frosted](https://store.steampowered.com/app/1070790/Freshly_Frosted/) 風の、
**4歳児向けドーナツ工場ウォッチング＆いじりゲーム**です。
パステルおもちゃ風の **3D 工場**（Three.js / WebGL、45° 見下ろしの透視投影カメラ）を、
iPhone / iPad の縦画面・横画面どちらでも遊べます。

パズルを「解く」ゲームではありません。

- 大量のドーナツが、いろいろな装置つきベルトコンベアで**半自動的に完成していく様子を眺める**こと
- ベルトや装置を**ちょっといじるだけで大ごとになり、ドーナツが別方向へ流れていく**こと

この2つを楽しむことに全振りした設計です。失敗・ゲームオーバーは一切ありません。
床に落ちたドーナツも「ぽよんぽよん」と可愛く転がって消えるだけです。

## あそびかた

| そうさ | なにがおきる |
| --- | --- |
| **なにもないゆかをタップ** | えらんだ装置が「ぽこっ」と生える（画面左のパレットでベルト🛤️/フロスター🎨/スプリンクラー🍬/ジャンプ台🦘を選択） |
| **じぶんで置いたものを長押し** | 「ずぽん」と撤去できる |
| ベルトをタップ | 矢印がくるっと回って、ドーナツの流れる向きが変わる |
| フロスター/スプリンクラー/トッパー/スタンパーをタップ | 色・スプリンクル・トッピング・かたちが切り替わる |
| 大きな矢印レバー（スイッチャー）をタップ | ドーナツの行き先ルートが切り替わる |
| しんごうゲートをタップ | とおせんぼ！ ドーナツが渋滞 → もう一度タップで一気に放出 |
| ドーナツをゆびでつまむ | 持ち上げて好きな場所（箱の中でも！）に置ける |
| ドーナツのもと（顔つきマシン）をタップ | すぐに1個ドーナツが出てくる |
| ゆかをタップ | きらきら（どこを触っても反応します） |

### 画面のボタン

- 🏭 … 11種類の「こうじょう」を選ぶ
- 🔊 / 🔇 … 音楽と効果音のオン/オフ
- 🐢 / 🐇 … ターボモード（工場全体が高速化）
- 🌈 … にじパワー！ 画面中のドーナツのデコがぜんぶランダムに変わる
- 🌧️ … **ドーナツのあめ！** 空から20個のドーナツが降ってきて、ベルトに乗ったものから流れ出す
- 左のパレット … ゆかに置く装置えらび（ベルト🛤️/フロスター🎨/スプリンクラー🍬/ジャンプ台🦘/プッシャー🥊/ブラックホール🕳️/たいほう💥）

しばらく触らないと、光る輪と👆の指が「ここを押してごらん」とお手本を見せます。

### 工場は生きている（ハプニング）

1〜2分ごとに、工場に「できごと」がランダムで起きます。

- ☔ **あめ** — ゆかがすべって、ベルトもドーナツも1.6倍速に
- 💡 **ていでん** — 真っ暗になり工場全停止。装置のランプだけが光る。**3回タップすると復旧**してファンファーレ！
- 📋 **おおちゅうもん** — スポナーが全開になり、ドーナツが4倍の勢いであふれ出す

### びっくり装置（どっきりこうじょう 🎁 ほか、パレットでも置ける）

- 💥 **たいほう** — ドーナツを詰めてチャージ→ドーン！と4マス先へ砲撃（画面が揺れる）
- 🕳️ **ブラックホール** — 渦に吸い込まれたドーナツは、ゴールのそばから「こっそり」出てくる（なくならない）
- 🥊 **のびちぢみプッシャー** — アームがガシャーン！と2マス伸びて、ドーナツをとなりのレーンへ押し出す
- 🏗️ **ロングアームクレーン** — ドーナツをつかんで宙づりのまま2マス先のレーンへ運ぶ
- 🔴 **ドミノスイッチ** — 押すと近くのベルトから順に、全ベルトがパタパタと90°回っていく
- 🥦 **やさいスイッチ** — 全ドーナツがブロッコリー/にんじんに変身！ トラックは野菜を「ぺっ」と吐き出す
- 🙃 **こうじょう反転レバー** — 盤面全体が点対称にひっくり返り、スタートとゴールが入れ替わる
- ⛈️ **かみなりぐも**（ときどき漂ってくる）— タップすると落雷！ 工場全停止＋ドーナツがビリビリ→数秒で復旧

## 装置いちらん（ガチ機械工場風・常時稼働）

すべての装置は「動く仕組みが見える」メカ構造で、アイドル中も歯車・ピストン・
かきまぜ機が動き続け、ドーナツ通過の瞬間に大アクションします。

- **ベルトコンベア** — 脚・フレーム・端ドラム・駆動歯車つきの立体コンベア
- **スポナー（スタート）** — **みどりの床＋大きな🍩かんばん＋光る出口リング**が目印。
  生地タンク＋かきまぜ機＋ピストンポンプ＋メーター＋湯気の出るえんとつ
- **はいたつトラック（ゴール）** — **赤いじゅうたん＋旗ガーランド**が目印。荷台にドーナツを
  積み、12個たまるとクラクションを鳴らして走り去り、新しいトラックがピッピッとバック搬入
- **フロスター** — かきまぜ機つきタンクタワー＋3連ノズルが噴射（色は7色切替）
- **スプリンクラー** — ホッパー＋回転ドラムからスプリンクルが降りそそぐ（4種）
- **クリーマー** — ポンプ＋らせんを描いて大しぼりする可動ノズル
- **トッパー** — 2関節ロボットアームがさくらんぼ等をガシャンと載せる（3種）
- **グレーザー** — スクリューコンベア＋シャワーヘッド＋光る滝
- **スタンパー** — 4本柱のメガプレスがズドン！と落ちて画面が揺れる（4形状）
- **スプリッター** — フライホイール駆動のポイント切替パドル
- **スイッチャー** — 光る大矢印＋ラチェット歯車＋切替レバー
- **クローナー** — ガラス管2本＋テスラコイル＋バチバチ電気アーク＋コピーの閃光
- **ランダマイザー** — ガチャ風回転ドラム＋チェイスライト
- **ワイルド** — 回転ターンテーブル＋カチカチフラップ
- **テレポーター** — 回転リング＋軌道を回るエネルギー玉＋点滅パイロン
- **ジャンプ台** — 大型コイルばね＋サイドピストンのカタパルト
- **ゲート** — しましま遮断バー＋カウンターウェイト＋モーター歯車＋点滅信号灯

## 動かしかた

ビルド不要（Three.js はリポジトリに同梱済み、外部通信なし）。

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → http://localhost:8000/donut-factory/
```

`index.html` をブラウザで直接開いても動きます。GitHub Pages にもそのまま置けます。
音はブラウザの制約により最初のタップ（スタート画面）以降に鳴り始めます。

## 技術メモ（3D）

WebGL（Three.js r147・UMD版を `vendor/` に同梱）による本格3D描画です。
シミュレーション層（レベル・装置の挙動・移動）と描画層を分離しています。

- `vendor/three.min.js` — Three.js r147（同梱・オフライン動作）
- `js/core.js` — 定数・ユーティリティ・色パレット
- `js/audio.js` — WebAudio 合成の効果音＋レベルごとに自動生成されるペンタトニックBGM（音源ファイルなし）
- `js/particles.js` — InstancedMesh 2つ（箱・球）で描く3Dパーティクル（紙吹雪・しぶき等）
- `js/donut.js` — ドーナツの状態（デコ・移動）。スプリンクル配置は Path2D 判定
- `js/donut3d.js` — ドーナツの3Dビュー。リングはトーラス、星/ハート/花は穴あき押し出し＋ベベル。
  スプリンクル/クリームはインスタンス描画、グレーズは光沢マテリアル切替
- `js/tiles.js` — 17種タイルの挙動（何が起きるか）のみ
- `js/render3d.js` — シーン・カメラ・ライト・17種装置の3Dビュー・おてほんガイド
- `js/levels.js` — ASCIIマップ＋凡例によるレベル定義
- `js/game.js` — グリッドシミュレーション・入力（レイキャスト）・HUD

### 3Dの設計

- **カメラ**: 固定の斜め見下ろし（45°）の**透視投影カメラ**。手前が大きく奥が小さい
  遠近感でジオラマの立体感を最大化。縦画面では 90° 回した方位から見てボードを最大表示
  （ボード全体が視野にちょうど収まる距離を毎回閉形式で計算）
- **ビジュアル**: パステルおもちゃ風。3段トゥーンシェーディング＋やわらかい影
  （HemisphereLight + DirectionalLight / PCFソフトシャドウ）
- **入力**: タッチ位置→ベルト面へのレイキャストでタイル/ドーナツを判定。
  マルチタッチ対応（複数の指で同時にいじれます）
- **軽さ**: ジオメトリ/マテリアルのキャッシュ共有、スプリンクル・パーティクルの
  インスタンス描画、ドーナツ上限で iPhone/iPad でも安定動作
