# ひかりのたび 〜ゆめのフロック〜

FROST（[App Store](https://apps.apple.com/pl/app/frost/id1234617736)）にインスパイアされた、
**4歳児向けのタッチゲーム**です。iPhone / iPad の縦画面・横画面どちらでも遊べます。

夢のような空の中を、群れになって飛ぶ「ひかりのこどもたち」。
指で光の道を描いて、同じ色のおうちの惑星まで連れて行ってあげましょう。

## あそびかた

| そうさ | なにがおこる |
|---|---|
| **ゆびで なぞる** | 光の道ができて、近くのひかりのこどもたちが道に沿って飛んでいく |
| **タップする** | 星くずが生まれて、みんなが遊びに集まってくる |
| **ほしを タップ** | 惑星が音を鳴らしてよろこぶ（惑星ごとに声がちがう） |
| **おなじ色のほしに とどける** | くるくる〜っと吸い込まれて、惑星がどんどん笑顔になる |
| **ぜんぶ とどけたら** | 花火とにじの大おまつり！ おまつり中は画面のどこを触っても花火が上がる |

- **まちがいも失敗もありません。** ちがう色の惑星にぶつかっても「ぽよん」と跳ね返るだけ。
- **マルチタッチ対応。** 2本指・3本指で同時に道を描けるので、親子で一緒に遊べます。
- しばらく触らないでいると、**光る指がお手本の道**をそっと見せてくれます。
- のこりが少なくなると惑星が強く引き寄せてくれるので、最後の1匹で詰まりません。

## たのしい要素

- **ボイド（群れ）シミュレーション** — 分離・整列・結合の3ルールで、本物の群れのように流れる
- **12のゆめの場面**（テーマ）をめぐる旅 — 海、空、花畑、深海、夜空、夕焼け、氷の森、雪の夜、朝焼け、さんごの海、にじのむこう…
- **7種類のなかま** — ひかりのこ・おさかな・ことり・ちょうちょ・くらげ・おほしさま・ほたる。初めて出会うときはお披露目ファンファーレ付き
- **顔のある惑星** — まばたきして、ひかりのこどもが届くほど笑顔が大きくなり、満タンで花が咲く
- **テーマごとの環境演出** — 泡、花びら、雪、流れ星、オーロラ、またたく星空
- **ぜんぶ合成音** — Web Audio API のペンタトニック音階だけを使うので、どこを触ってもきれいな音になる。描いた道はそのまま楽器に
- **ごほうび** — クリアするたびに ⭐ がたまる（自動保存。次に開いたときは続きから）

## あそびはじめかた

`index.html` をブラウザで開くだけです。ビルド・外部ライブラリ・通信は一切不要
（すべてバニラJS + Canvas + Web Audio、アセットも全部コードで生成）。

iPhone / iPad で遊ぶには、GitHub Pages などで公開して Safari で開くのがおすすめです。
「ホーム画面に追加」すると全画面のアプリのように遊べます。

ローカルで試すなら:

```bash
cd frost-dream
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## ファイル構成

```
frost-dream/
├── index.html          エントリポイント（タイトル画面・HUD含む）
├── css/
│   └── style.css       タイトル・HUD・セーフエリア対応
└── js/
    ├── util.js         汎用ヘルパー（乱数・色・補間）
    ├── audio.js        Web Audio シンセ（チャイム・ファンファーレ・環境音）
    ├── effects.js      グロースプライト・パーティクル・背景（空/星/オーロラ/雪/泡/花びら/流れ星）
    ├── boids.js        ひかりのこどもたち（群れシミュレーション＋7種の姿の描画）
    ├── planets.js      顔のある惑星（吸い込み・満開・タップ反応）
    ├── levels.js       12テーマのレベル定義
    └── main.js         メインループ・マルチタッチ入力・状態遷移・ヒント・お祝い演出
```

## 技術メモ

- `viewport-fit=cover` + `env(safe-area-inset-*)` でノッチ対応
- `touch-action: none` + `preventDefault` で iOS のスクロール・ピンチズームを抑止
- 最初のタップで AudioContext をアンロック（iOS の自動再生制限対応）
- `shadowBlur` は iOS で重いため、事前描画したグロースプライトの `drawImage` で発光表現
- `devicePixelRatio`（上限2）対応の高解像度描画
- 惑星は正規化座標で配置しているので、画面回転・リサイズしてもレイアウトが崩れない
- 進行状況は `localStorage` に保存（プライベートモードでも例外にならないようガード済み）
