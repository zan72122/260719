# ひかりのたび 〜ゆめのフロック〜

FROST（[App Store](https://apps.apple.com/pl/app/frost/id1234617736) /
[Behance](https://www.behance.net/gallery/59255795/FROST-A-Dream-Odyssey)）に
インスパイアされた、**4歳児向けのタッチトイ・ゲーム**です。
iPhone / iPad の縦画面・横画面どちらでも遊べます。

本家と同じく、**画面のほぼすべてが光の粒子でできています。**
WebGL により数千〜2万超の粒子をリアルタイムに群れシミュレーションし、
指で描いた「光の川」に群れが流れ、時々あつまって **文字や生き物の形** を作ります。

## あそびかた（おもちゃとして自由に）

| そうさ | なにがおこる |
|---|---|
| **ゆびで なぞる** | 消えない「光の川」ができて、群れがリボンのように流れつづける（3本まで・マルチタッチ可） |
| **おしっぱなし** | 指のまわりに光の渦が巻く |
| **トンとタップ** | 波紋が広がって群れがふわっと散り、また戻ってくる |
| **1.5びょう ながおし** | その場に ハート・星・花・にじ が粒子で咲く |
| **ほしを タップ** | 惑星が音で返事をする（惑星ごとに声がちがう） |
| **おなじ色のほしに ながす** | 粒子が捕まって惑星のまわりを回るリングになり、満ちると笑顔が満開に |

- **失敗も強制もありません。** 惑星は「置いてあるおもちゃ」。ぜんぶ満ちたら大きなお祝いのあと、次のゆめの場面にゆっくり変わります。
- しばらく触らないと、**光る指がお手本の川**をそっと見せてくれます。

## 群れが「形」を作る（フォーメーションエンジン）

- 惑星が満ちるたび、群れが **数字「1」「2」「3」…** を描く
- ぜんぶ満ちたら **「やったね」**、名前を設定していれば **こどもの名前** を粒子が描く（タイトル画面の「👶 なまえを おしえる」から設定・localStorageに保存）
- 待っていると時々、群れが **くじら・ちょうちょ・とり・りゅう** のシルエットになって画面を泳いで溶けていく
- 長押しで **ハート・星・花・にじ** がその場に咲く

## 種（species）の性格とメタスワーム

テーマごとに1〜4種の群れが登場し、性格の組み合わせで思いがけない動き（メタスワーム）が生まれます。

- **ついていく種** … 別の色のあとを追う。白を導くと青がついてくる「ひつじかい遊び」
- **はずかしがりの種** … 指から逃げる。うしろから押して導く
- **うずまきの種** … 自分たちで渦を巻く
- ふつうの種は描いた川に強く流れる（12テーマ：海・空・花畑・深海・夜空・夕焼け・氷の森・雪の夜・朝焼け・さんごの海・にじのむこう…）

## 技術

- **WebGL ポイントスプライト + 加算合成**。半解像度のピンポンFBOに残像を蓄積して、全粒子に光の尾を付ける（`shadowBlur`不使用）
- **O(n) 群れシミュレーション**：粗いグリッドに種ごとの平均速度・重心を集計して整列/結合/分離＋解析的カールノイズの流場。数万粒子でもCPU1コアで足りる
- **光の川**はグリッドに方向ベクトルとして焼き込むフローフィールド方式（粒子側はセル1回参照のみ）
- **フォーメーション**はオフスクリーンCanvasに文字/シルエットを描いてピクセルをサンプリングし、形の中心に近い自由粒子から割り当ててスプリングで整列
- 起動直後のタイトル画面でフレーム時間を計測し、**粒子数を3,500〜24,000で自動調整**
- WebGL不可の環境は Canvas 2D フォールバック（粒子少なめ）で動作
- 音はすべて Web Audio のペンタトニック合成（外部アセットなし）。群れの活発さに応じたきらめき音つき
- iOS対応：safe-area、ズーム抑止、初回タップでのAudioContextアンロック、devicePixelRatio対応（上限2）
- 進行（テーマ・⭐・名前）は localStorage に保存

## あそびはじめかた

`index.html` を開くだけ。ビルド・外部ライブラリ・通信は一切不要です。

```bash
cd frost-dream
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

iPhone / iPad では GitHub Pages などで公開して Safari で開き、
「ホーム画面に追加」すると全画面で遊べます。

## ファイル構成

```
frost-dream/
├── index.html          エントリポイント（タイトル・なまえ設定・HUD）
├── css/style.css
└── js/
    ├── util.js         汎用ヘルパー
    ├── audio.js        Web Audio シンセ（チャイム・和音・きらめき・環境音）
    ├── themes.js       12テーマと種（species）の定義
    ├── gl.js           WebGLレンダラ（トレイルFBO・背景シェーダ）+ 2Dフォールバック
    ├── sim.js          群れシミュレーション（グリッド集計・川・渦・波紋・惑星捕獲）
    ├── formations.js   文字・シルエットのサンプリングと整列
    └── main.js         状態遷移・入力・惑星・お祝い・画質自動調整
```
